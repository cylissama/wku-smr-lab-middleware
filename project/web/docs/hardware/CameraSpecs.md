
# Camera Specs
1pcs 5MP 1/2.7" 5-50mm M12-Mount lens raspberry pi

Focal length: 5-50mm

Resolution / Pixel Format: 5 Megapixels

Optical Format: 1/2.7"

Mount Type: M12 x 0.5 thread pitch

Focal Track Length: 62.3mm ± 0.3mm

Back Focal Length: 10.53mm, 4.56mm

The lens screws into the lens mount the camera board then connects to the pi through USB, turning the lens can change the zoom or focus.
